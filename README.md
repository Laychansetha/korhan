# រមណីយដ្ឋានកោះហាន | Koh Han Resort Community Ecotourism Website

A modern, responsive, and image-first homepage for **Koh Han Resort** (រមណីយដ្ឋានកោះហាន), a Community-Based Ecotourism site in the **Stung Treng Ramsar Wetland**, Cambodia.

## 🌿 Highlights

- **Bilingual Support**: Full dynamic toggle between Khmer (ភាសាខ្មែរ) and English.
- **Visuals-First Design**: Showcases authentic local photography of the flooded forests, sandbars, and wooden community cabins.
- **Interactive Destinations Gallery**: Showcases the 9 key locations with category filters and a high-resolution Lightbox modal.
- **Tour Packages & Pricing**: Displays accurate tiered pricing for half-day, full-day, 2D1N camping, and 3D2N adventures based on group size.
- **Regional & Kayaking Route Map**: Illustrated map preview with click-to-zoom modal.
- **Direct Contacts**: Integrated Telegram channel, WhatsApp, phone numbers, and Google Maps location.
- **Mobile Optimized**: Floating action bar for one-tap calling, messaging, and navigation.

## 🚀 How to Deploy on GitHub Pages

1. **Create a new repository** on GitHub (e.g. `koh-han-website`).
2. **Push your code**:
   ```bash
   git init -b main
   git add .
   git commit -m "Initial commit of Koh Han Resort website"
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
3. **Enable GitHub Pages**:
   - Go to your repository on GitHub.
   - Click **Settings** > **Pages** (in the left sidebar).
   - Under **Build and deployment > Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. In about 1–2 minutes, your website will be live at:
   `https://<your-username>.github.io/<repo-name>/`
